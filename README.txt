GIRLFRIEND PROPOSAL WEBSITE

1. Open index.html in a browser to preview it.
2. Replace:
   [Her Name]
   [Your Name]
   [Special Date]
3. Replace the three image URLs in the CSS under .photo-card with your own image links,
   or use local files such as:
   url('photos/photo1.jpg')
4. To publish free:
   - GitHub Pages
   - Netlify Drop
   - Vercel

The website works on phones and computers.
